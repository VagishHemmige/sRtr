## Implementation and test map

The following shorthand denotes actual inspected code, not presumed capabilities:

- **O:** `R/add_time_to_event_variables.R`: `srtr_time_to_event()` (lines 26–97), `add_txf_outcomes()` (182–276), internal `add_time_to_event_outcomes()` (321–498), `.srtr_death_censor()` (511–520). Existing `test-add_txf_outcomes.R` was read fully; outcome test names and relevant censor/tie cases in `test-add_time_to_event_variables.R` were inspected. O computes binary/date/time columns, not competing-risk models, relisting linkage, score construction or external cancer ascertainment. The orchestration function is not exported in NAMESPACE.
- **D:** `R/composite-death-variable.R`, inspected fully: OPTN→SSA→TFL coalescing or optional earliest date, source/conflict columns. This is not a study-specific mortality observation window.
- **L:** `R/load_srtr_file.R` interface/lookup inspected; names, projection, TRR filtering and file-key metadata; corresponding test inventory inspected. No external cohort linkage or entity-resolution API exists in the inspected exports.
- **F:** `R/apply_srtr_factors.R`, inspected fully, and factor-test inventory: maps codes to labels; does not establish study-specific categories.
- **M:** `R/srtr_normalize_missing.R`, inspected fully, and missing-test inventory: explicit/default value replacement, not imputation or incident-disease ascertainment.
- **G:** `R/calculate_geography_coverage_gain.R` interface inspected: polygon coverage/count aggregation, not historic ZIP crosswalks or transplant access denominators. No geographic calculation implementation finding is asserted here.
- **Score gap:** exported score function is `add_pdri()` only (NAMESPACE inspected). No KDPI, GFR, MELD, CHARM, PVR or liver-score implementation was found in the R file inventory. Their absence is not a defect in a package that has not promised them.

Existing outcome tests cover death windows, same-day graft/death alternatives, missing last follow-up, KP organ separation and empty-positive-event sets. Proposed tests extend interactions and semantics rather than duplicating those cases. Deferred recipe suggestions in this ledger are unexecuted; the consolidated report separately records six executed checks.

## Consequential primary-source verification

1. **PMC11152206**, original PMC, Patients and methods → Primary and secondary outcomes (retrieved lines 182–184) and Statistical analysis (198): distinguishes death-inclusive liver graft survival from relisting/retransplantation with death censoring. This establishes a published study definition, not the clinical meaning or provenance of `TFL_GRAFT_DT` in any SAF release. Relevant code remains O lines 393–421.
2. **PMC10942003**, [publisher full text](https://www.frontierspartnerships.org/journals/transplant-international/articles/10.3389/ti.2024.12309/full), Materials and Methods → Study population (190–196), Definitions (201–203), Statistical analyses (207–209): the Finnish early-loss exclusion is explicit; the SRTR paragraph specifies DBD kidney-only recipients on pretransplant dialysis. The primary outcome includes death with a functioning graft, with a death-censored sensitivity analysis. These choices are practice examples, not universal SRTR rules or KDPI defining authority.
3. **PMC10919340**, original PMC Methods (195–209): incident cancers come from linked registries, follow-up stops at specified competing observation ends, and transplant episodes can repeat within a person. This supports an explicit limitation on claims made for O, not a claim that all SAF malignancy entries are incorrect. Original Methods were retrieved initially; a later find request returned CAPTCHA.
4. **PMC11177818**, original PMC Methods → Exposures and Outcomes (140–147) and Analysis (148–153): the paper excludes acute rejection from its outcomes because of sensitivity concerns and uses a specified imputation approach for competing death. It cannot validate the package's rejection-date proxy. The cited original validation study, supplements and underlying imputation method were not independently read; no quantitative sensitivity estimate or estimator correctness claim is made.

Blocked originals: PMC10857737, PMC11427033, PMC11606542, PMC11342767, PMC11104730 and PMC10895807 returned CAPTCHA; PMC11152206 first returned CAPTCHA then succeeded without trailing slash; PMC10942003 succeeded at publisher after PMC CAPTCHA. PMC11427033 search supplied Results and an abstract, not outcome definitions. Other rows were mapped from annotations only. No supplements, original score formula sources, PTR dictionary or live SAF release documentation were retrieved in this pass. Thus full primary-source confirmation of every annotation remains a stated evidence gap, while every assigned entry has a package disposition.
