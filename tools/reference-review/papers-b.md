## Code and test mapping key

- **T**: R/add_time_to_event_variables.R:27–96, exported `srtr_time_to_event`: caller-supplied origin/event/censor, event always wins over censor, default one-day epsilon, binary state; tests/testthat/test-add_time_to_event_variables.R:263 covers negative times with epsilon zero.
- **O**: same file:320–496, internal (not NAMESPACE-exported) `add_time_to_event_outcomes`: transplant origin, death-window choices, death-censored graft failure, follow-up-derived malignancy/rejection. Tests in test-add_time_to_event_variables.R:32–260 cover mortality windows/graft death censoring, and test-add_txf_outcomes.R:165–223 cover KI/KP orchestration.
- **F**: same file:183–271, exported `add_txf_outcomes`: first positive follow-up form date per TRR_ID; treated rejection only; absent positive forms return NA. Tests/testthat/test-add_txf_outcomes.R cover KI/KP forms but not endpoint observation coverage.
- **D**: R/composite-death-variable.R:25 onward, `srtr_composite_death`, precedence OPTN/SSA/TFL or earliest, with conflicts; tests/testthat/test-composite-death-variable.R.
- **L**: R/load_srtr_file.R:53–220, `load_srtr_file`: table/column selection and TRR filtering, labels and file metadata. tests/testthat/test-load_srtr_file.R cover filtering/selecting; no general person-registration/donor-pair/linkage API appears in NAMESPACE.
- **G**: R/calculate_geography_coverage_gain.R:92 onward and R/center-location.R:45 onward: area coverage and current HRSA centers, not historical residential ZIP/ACS linkage; geographic tests do not validate such a linkage.
- **S**: R/add_PDRI.R:57, `add_pdri` only; no EPTS/KDPI/ACLF/CAS/eGFR implementation in NAMESPACE. R/srtr_normalize_missing.R replaces specified values; it does not define paper-specific imputations.
